50言語

システムの言語に合わせるほか、設定で個別に選べます。

端末の中だけ

端末内のデータベースに保存し、保存時に暗号化します。内容はアップロードしません。

12色の文字色

太字と取り消し線も編集ツールバーの上、書きながらすぐ使えます。

6階層のグループ

ノート → グループ → メモ。好きなだけ深く分けられます。

データ消失防止

急に電話が来ても、アプリが中断されても、電池が切れても、保存していなかった内容は自動で復元されます。保存ボタンを探す必要はなく、記録がもっと気楽に。

グループ分け

「ノート → グループ → メモ」の多階層管理で複雑な整理にも対応。分類せずにサッと書くこともでき、自由自在です。

ワンタップ保存

Safari などで気になる文章やリンクを見つけたら、「共有」からミニメモを選ぶだけ。内容が自動で受信箱に入り、コピーと切り替えを繰り返す必要がありません。

一覧もすっきり

リッチテキストエディタは太字・打ち消し線に加え、12色のプリセットパレットを用意。前回使った色を自動で記憶し、毎回設定し直す手間を省きます。タイトルは本文の書式を引き継ぐので、一覧のプレビューがすっきり見やすくなります。

よくある質問

よく聞かれること

ミニメモは本当に無料ですか？

はい。ダウンロードも利用も無料で、書くための機能に有料の制限はありません。

保存する前に閉じてしまったら、書いた内容は消えますか？

消えません。編集中は下書きが端末に保存され続けます。開き直せば自動で戻り、カーソルがどの行にあったかまで覚えています。

アカウント登録は必要ですか？

不要です。登録もログインもありません。開いてすぐ、1タップで書き始められます。

対応している端末は？

iPhone と iPad、iOS 16.0 以降です。

メモはどこに保存されますか？

お使いの端末の中です。保存時に暗号化され、メモの内容がサーバーへ送られることはありません。

Safari から直接保存できますか？

できます。Safari などで「共有」をタップしてミニメモを選ぶと、リンクや文章が受信ボックスに入り、新しいメモになります。

ミニメモを使ってみる

App Store で無料。iPhone と iPad、iOS 16.0 以降。
